This file describes API changes in the examcheck activity module.
Information provided here is intended especially for developers.

=== 5.1-r2 ===

* New capability mod/examcheck:manageseats (editingteacher, manager) gates the
  Seats tab (seat assignment, edit seats, CSV import/export).
* New tables examcheck_seats (the per-activity seat list; structure, always
  backed up) and examcheck_seat_users (1:1 user/seat assignments; user data,
  backed up under the userinfo setting, covered by the privacy provider and
  cleared by course reset — the seat list itself survives reset).
* New public API \mod_examcheck\local\seats — seat list CRUD (replace_list)
  and assignment handling (assign/unassign, get_user_seat_labels, counts).
  Future features (random distribution, check-time seat capture) should build
  on it.
* New web services: mod_examcheck_assign_seat, mod_examcheck_unassign_seat,
  mod_examcheck_search_seat_candidates (all ajax, gated by manageseats).
* New shared helper \mod_examcheck\local\checker::resolve_effective_group()
  resolves the group a user is confined to without throwing (used by the
  roster table and the seat candidate search).
* The shared scan/mark outcome structure (\mod_examcheck\local\outcome) gained
  an optional "seatlabel" field, surfaced in the scanner modals.
* New events: \mod_examcheck\event\seat_assigned, seat_unassigned.
* New examcheck.enableseats column (default 1) with the defaultenableseats
  admin setting: a per-activity toggle for the whole seats feature. When 0 the
  Seats tab, seats.php and the roster/export seat columns are hidden/blocked,
  the outcome "seatlabel" is always empty, and the three seat web services
  throw a "seatsdisabled" moodle_exception. Seat data is never deleted; the
  column is included in backups.
* The activity form's "Attendance settings" section was renamed to "General
  settings" (lang string attendancesettings removed, generalsettings added)
  and now hosts the enablescanner and enableseats toggles; every field in
  "Scanning defaults" (including scanfield) is hidden while the scanner is
  disabled.
* The roster table no longer renders a dedicated scan-match-field column: it
  shows the site's configured identity fields (core_user\fields, now including
  custom profile fields) per the viewer's permissions. scanfield now only
  affects the scanner lookup.
* New dynamic table \mod_examcheck\table\seat_assign (unique id
  "examcheck-seatassign-{cmid}") with its mandatory seat_assign_filterset,
  replacing the hand-rolled seat assignment markup. Sortable by seat (the
  authored sortorder, reversed on descending) and by assigned student.
* New output class \mod_examcheck\local\roster_exporter::columns_and_rows()
  builds the roster export. export.php no longer emits a hardcoded idnumber
  column: it emits the identity fields the exporting user may see, matching
  the roster table. Sites whose showuseridentity omits idnumber will no longer
  find it in the downloaded file.
* \mod_examcheck\local\seats_exporter::columns_and_rows() was replaced by
  seat_columns_and_rows(), student_columns_and_rows() and build_zip(). The
  export now offers two scopes: the seat list as one CSV, or the seat list
  plus the roster as seats.csv + students.csv in a zip. students.csv holds one
  row per roster student, with an empty seat when unassigned.
* \mod_examcheck\local\seats_importer accepts the new row shapes: a student
  with no seat is unseated, a row blank on both sides is skipped, and a file
  with no student column (username/email/idnumber) only describes the seat
  list and never clears an assignment. Previously such a file emptied every
  seat it named.
* New form \mod_examcheck\form\seats_export_form (the export scope picker).
  The seats export no longer uses download_dataformat_selector, so it no
  longer honours the dataformat request parameter.
* Lang strings importseats, exportseats and importseatsintro were removed in
  favour of import, export and importintro; exportscope, exportscope_seats,
  exportscope_seatsandstudents and exportscope_help were added.

=== 5.1-r1 ===

* First public release. Public API:
  - \mod_examcheck\local\checker — roster, marking (with conflict detection),
    unmarking, scan resolution (with optional extraction regex) and per-step
    progress.
  - \mod_examcheck\local\steps — step CRUD and reordering.
  - \mod_examcheck\local\scanfield — scan field menu, user lookup and the
    apply_regex() / is_valid_regex() extraction helpers.
  - Web services: mod_examcheck_mark_user, mod_examcheck_unmark_user,
    mod_examcheck_bulk_action, mod_examcheck_scan_lookup,
    mod_examcheck_get_marks.
* Scanner decodes via zxing-wasm (a WebAssembly build of upstream zxing-cpp).
  The vendored JS loader lives at amd/src/zxingwasm.js and the WebAssembly
  binary at wasm/zxing_reader.wasm (fetched at runtime; served as a regular
  static file, outside amd/ so grunt amd never processes it).
